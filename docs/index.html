Browser pipeline

1 · PyramidEstimate at reduced scales while preserving full-resolution PSF support.
2 · Latent imageFFT data fidelity + sparse gradients; optional dark-channel projection.
3 · PSF updateGradient-domain normal-equation estimate, positivity, pruning and recentering.
4 · RestoreRegularized FFT deconvolution plus optional PnP or dual-extreme refinement.

Adaptive auto runs both dark-channel-guided and gradient-only blind estimation. It selects the candidate using the observed image only: reblur fidelity, artifact growth and PSF plausibility. Manual line, drawn PSF, and uploaded PSF bypass blind estimation and feed the chosen kernel directly into the same restoration stage.

The Python implementation remains the authoritative research pipeline. This page mirrors its algorithmic structure in dependency-free JavaScript and uses browser-friendly FFT/optimization approximations so it can run as a static, zero-third-party-dependency browser application. Legacy result/kernel assets are never used here.
Tip: if a dark-channel estimate creates a branchy or implausible kernel, try Adaptive auto first—it also evaluates the gradient-only candidate. For known camera motion, switch to Manual motion line. For unusual curved motion, draw the PSF directly or upload a measured kernel image.
