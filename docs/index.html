What the browser lab does

1. Builds a motion-line PSF from the selected length and angle. 2. Alternates forward blur, measurement residual, and back-projection. 3. Applies smoothness and optional extrema-aware detail control. 4. Uses an artifact guard to reduce unstable updates.

The browser tool is intentionally lightweight and dependency-free. It is not a JavaScript reproduction of the repository's full multi-scale Python blind-PSF solver. For authoritative experiments use docker compose run --rm test.

Tip: if you see halos, lower the data step or increase smoothness. For long motion blur, estimate the angle first and then tune kernel length. Processing stays entirely on your device.
