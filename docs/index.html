How this browser version works

1. A motion-line PSF is created from the selected length and angle. 2. A regularized iterative inverse step alternates forward blur, residual back-projection, and smoothness control. 3. Optional dark/bright-extrema guidance restores local contrast only where the image contains strong evidence. 4. An artifact guard attenuates updates that create too much clipping or high-frequency growth.

This single HTML file is intentionally lightweight and dependency-free. It is an interactive approximation, not a browser port of the full multi-scale Python blind-kernel solver. For reproducible research results, use docker compose run --rm test or the Python CLI.

Tip: for long camera shake, first use Estimate angle, then increase kernel length until duplicated edges begin to converge. If halos appear, increase smoothness or lower the data step. All processing is local to the browser.
