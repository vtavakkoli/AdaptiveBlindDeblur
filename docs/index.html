Getting a better result

Start with automatic estimation. If motion trails remain, choose Straight motion and adjust its length and angle. For uniform softness, try the disk model.

Increase noise suppression if grain or ringing appears. Check at 100% before exporting. Different blur across the image, clipped highlights, and lost detail can limit recovery.
